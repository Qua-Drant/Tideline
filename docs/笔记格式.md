# 笔记格式（v0.2，潮线）

从头设计，不兼容 0.32 / life-os-app 的旧格式。文件夹名先写死在 `src/data/index.js` 的 `FOLDERS`，以后放进设置。
引用别的笔记一律写成链接 `"[[标题]]"`（按文件名对上，不看文件夹）。

## 各类笔记

| 类 | 位置 | 属性（frontmatter） | 正文 |
| --- | --- | --- | --- |
| 设置 | `潮线/配置.md` | `habits: [{id, name}]`、`questions: [{id, title}]`（id 创建后不变，设置页新增的是 `habit_5`、`question_3` 这样）、`ai: {askRead, noWrite, autoWrite}`（AI 的三张保护名单，没写就用默认：读取前先问 `日记/`、`人物/`；不能改当前仓库的 Obsidian 配置目录与 `潮线/配置.md`）、`effortScaleHours`（投入比例尺，小时）、`lists: [{title, archived}]`（任务清单）、`views: [{title, filter}]`（任务页保存的视图）、`ideaTags`（想法标签）、`areas: [{id, title}]`（生活之轮的领域） | 说明文字，插件不读 |
| 日程 | `潮线/日程.md` | `events: [{date, time, title, description}]` | 手写日程和本机订阅日程一起按日期显示在思索规划。今日时间轴只画有时刻的日程 |
| 日记 | `日记/YYYY-MM-DD.md` | `habits: {id: true/false}`（没写 = 没记录）、`scores: {id: 1–10}`、`effort: {名称: 小时}`、`highlight`（往年今日用的一句话）、`quote`（这一天的一句话；今天的就是本周一句话） | `## 随手记` 下每行 `- HH:MM 内容`；`## 完成`（往年回看）；`## 成就`、`## 感恩`（复盘页） |
| 任务 | `任务/标题.md` | `status: open / in_progress / done / cancelled`、`scheduled`、`project: "[[项目]]"`、`list`（清单名）、`people: ["[[人物]]"]`、`priority: highest / high / medium / low`、`discuss`（见面时要谈）、`repeat`（如“每周”）、`focus: 1–3`（今日重点的顺序）、`completed`；0.4 起可选：`order`（货单里同一层的手动顺序，10、20、30……）、`parent: "[[父任务]]"`（子任务）、`pinned: true`（置顶）、`tags`（标签，`example` 仍是示例标记）、`time: "HH:MM"`（时刻；今日时间轴不画）、`remind: 0 / 5m / 30m / 1h / 1d`（有时刻时到点提醒）、`comments: ["YYYY-MM-DD HH:MM 内容"]`（评论）；0.5 起可选：`mode: checklist`（详情用检查项模式显示，检查项仍是正文里的 `- [ ]` 行）；`repeat` 认得出的写法：每天、每周、每周一、三、每月、每年、工作日、每 N 天 / 周 / 个月 | 整篇是任务的说明（Markdown，可以有清单、表格、`[[链接]]`）；第一段是简短说明 |
| 项目 | `项目/标题.md` | `status: active / planned / paused / completed / archived`、`due`、`resume`（暂停后哪天回来）、`completed`、`goals`、`people`、`ideas`、`literature`（都是链接列表）、`milestones: [{title, state: done / in_progress / open}]` | 第一段是项目说明 |
| 人物 | `人物/姓名.md` | `initial`（头像里的字，默认取第一个字）；0.9 起可选 `cadence`（每隔几天联系一次：7 / 14 / 30 / 90，或别的天数；不写就不提醒） | `## 记录` 下每行 `- YYYY-MM-DD 内容`。插件只在列表末尾追加（记一笔、见面了的结论写成 `- 日期 见面：结论`），撤销时只去掉刚加的那几行；这一节里自己写的段落不动 |
| 目标 | `目标/标题.md` | `planned`（每周计划投入，小时）；0.8 起可选：`status: paused / done`（不写就是进行中；旧笔记只写了 `resume` 的也算暂停）、`resume`（暂停后哪天回来，只在暂停时写）、`due`（截止日期）、`completed`（达成的日期，只在达成时写）。和项目的关联只写在项目笔记的 `goals` 里 | 插件不读不改，“在 Obsidian 打开”后自己写 |
| 想法 | `想法/标题.md` | `stage: seed / growing / ready / adopted / parked`、`review`（待回顾）、`tags`、`source`（来自哪个项目，链接）、`created` | 整篇是想法 |
| 文献 | `文献/标题.md` | `stage: inbox / skimmed / to-deep / deep-done / dropped`、`authors`、`year`、`type`、`added`、`started`、`read`（读完的日期）、`keywords`、`favorite`、`progress`（0–100）、`projects` | 第一段是结论；`## 摘要`、`## 要点`（每行 `- 小标题：内容`）、`## 摘录`、`## 笔记` |
| 书籍 | `书籍/标题.md` | 同文献，`stage: want / reading / done` | 同文献 |
| 指引 | `潮线/指引/标题.md` | `subtitle`、`category: writing / note / code / data / clean`、`risk: 0–3`、`scope: [读当前页, 读日记, 改文件, 删改]`（各 0/1）、`order` | 整篇是提示词 |
| 季度 | `潮线/季度/YYYY-Qn.md` | `wheel: {领域 id: 1–10}`、`harvest: [{title, done}]`、`directions: [{icon, title, progress}]`、`experiments: [{title, done, trend}]`、`metrics`、`tasks`、`hours`、`time`（季度回顾的几组数字） | 第一段是这一季的一段话 |

## Zotero 文献（0.7）

装了 Obsidian 插件 Zotero Integration（`obsidian-zotero-desktop-connector`）时，它的导入文件夹（每个导入格式的 `outputPathTemplate` 里 `{{` 之前的文件夹，以及 `noteImportFolder`；设置 › 笔记 › Zotero 文献可以另填）里的笔记也算文献：
- 显示名用属性 `title`（文件名常是 citekey）；作者取 `authors` / `author` / `creators`（数组或 {firstName, lastName}）；年份取 `year` / `date` 里的四位数；类型取 `itemType`；关键词取 `tags`；摘要取 `abstract` 属性或 “Abstract / 摘要”标题下的文字；摘录取 “Annotations / Highlights / 摘录 / 标注”标题下的列表项、引用块或段落（任意级别标题）。
- 笔记里有 `zotero://open-pdf/…` 或 `zotero://select/…` 链接时，“打开 PDF”在仓库里找不到 PDF 就用它在 Zotero 里打开。
- 潮线改阅读阶段、收藏等照常写进属性；不改这类笔记的文件名（Zotero Integration 按 citekey 找回它）；项目关联它时链接写文件名 `[[citekey]]`。
- Zotero Integration 重新导入同一篇时会按它的模板重写笔记，模板里没有保留的属性（如 `stage`）可能被覆盖：要保留就在模板里用它的 `{% persist %}` 块或把这些属性写进模板。

## 插件算出来、不存的东西

- 目标的本周已投入：本周每天日记 `effort` 里、名称是该目标下某个项目的那些小时数加起来（目标详情纸里按项目列出）。截止日期过了而没达成时，日期显示成提醒色，不另存。
- 人物的上次联系：`## 记录` 里最晚的日期。设了 `cadence` 而离上次联系超过这么多天（或从没记过），邮包挂提醒色的小签并排到最前，不另存。
- 任务页邮包的顺序：该联系了的在前，再按待沟通件数从多到少，再按最近联系。
- 复盘页的完成趋势（12 周）：按任务的 `completed` 日期数。
- 往年今日：往年同月同日的日记（`highlight` 与 `## 完成`）。
- 大脑默认显示哪些节点：目标、活跃项目及其关联的想法与文献、今日重点、人物、在读和读完的书。
- 思索规划按周展开订阅日程，全天项标“全天”。想法网页链接按正文渲染，保存的正文仍是原 Markdown。
- 知识库的读书阶段可为进度环提供显示下限，浏览记录不写回 `progress`。打开 PDF 时读取笔记里的仓库附件链接，可用属性链接、正文链接或嵌入，无须新加字段。

季度笔记里的 `metrics`、`tasks`、`hours`、`time` 现在是手写的；以后改成按任务、日记自动算（睡眠、运动次数这类没有记录的除外）。

## 示例航程

首次起航里可以装（只在仓库还没有任务和日记时）：一组覆盖各页的笔记，属性里带 `tags: [example]`，日期平移到安装那天。装了哪些记在这台设备上，设置 › 数据 里“清除示例”只删这些（进回收站）。

## 插件写入的地方

都只改变了的那一处，经 Obsidian 的 `processFrontMatter`（属性）/ `vault.process`（正文）。

- 今日页：完成 / 重新打开任务（可撤销；0.9.4 起和任务页同一套，见下方“完成任务”）、在没有今日重点时挑选当天任务（写入 `focus: 1`，可撤销）、习惯三态、自问打分、随手记（追加到 `## 随手记`）。
- 其余七页：页面改了哪条数据，就把那一条变了的属性写回对应笔记（`src/data/persist.js` 逐条比较）。
  - 新建的任务、项目、想法：建新笔记（文件名用标题，重名加序号）。
  - 思索规划的日期拖放写任务的 `scheduled`，拖到未排期移除该日期。项目海图拖到其他水域写项目 `status`，到对岸完成时补 `completed`。
  - 改了标题：重命名笔记（Obsidian 会顺带更新指向它的链接）。
  - 删除任务（加任务后点“撤销”）：用 Obsidian 的删除，进回收站，可以找回。0.9.4 起只删显式删除过的任务、目标、人物（删除、撤销新建、撤销完成记录），条目只是从页面数据里消失不会删笔记。
  - 完成任务（今日页、任务页、项目页、见面了都一样，`src/data/complete.js`）：普通任务写 `status: done` 与 `completed`（当天），还没完成的子任务一并完成；重复任务（有 `repeat` 和 `scheduled`）另建一篇完成记录（同标题加序号，`status: done`、`completed`、原来的 `scheduled`，不带 `repeat`），原任务的 `scheduled` 顺延到今天之后的下一次、正文里的 `- [x]` 清成 `- [ ]`。`completed` 只在完成的那一下写，笔记里没有的不会补。
  - 改正文时属性块原样保留，CRLF 换行的笔记写回后仍是 CRLF（`src/data/frontmatter.js`）。
  - 清单、保存的视图、想法标签：写进 `潮线/配置.md`。清单名称唯一，`lists[].title` 与任务的 `list` 保存同一个完整名称（可含冒号、引号），不写临时编号。原有任务的 `list` 暂时不在配置中时保留原值。
  - 写入中继续操作时保持当前模型，按后续修订再写一轮；离开页面继续写，关闭视图等待写完。部分失败会反馈并保留待写状态，下次操作重试，不重复创建已经建成的笔记。
  - 生活之轮的分数、季度收获与实验的勾选：写进当季的 `潮线/季度/` 笔记。
- 设置页：三张清单（习惯、每日问题、生命之轮领域）、AI 保护名单写进 `潮线/配置.md`。首次起航：确认后建配置笔记；开始导览时把勾选的习惯等追加进去。
- 记一笔：任务、想法、项目各建一篇新笔记；随手记、成就、感恩追加到今天日记的 `## 随手记`、`## 成就`、`## 感恩`（没有这一节就在文末加上）。
- 只在这台设备上（Obsidian 的本机存储，不写笔记）：设备偏好（含 `device.tooltips` 悬停功能提示，默认 `false`；`device.motion` 0.3 起只有 `brief` 滑动 / `off` 关闭，旧的 `full` 读入时按 `brief`）、AI 助手设置（0.3 起 `ai.provider` 默认供应商，`ai.providers.{claude,codex,gemini,custom}` 各存 `on`、`command`、`args`、`name`、`apiKeySecret`——密钥本身在 Obsidian 的密钥库里，这里只存名字；0.2 的 `exe` 不再使用，`apiKeySecret` 搬到 `providers.claude`）、AI 对话列表、装过的示例清单、是否问过清除示例、是否起航过、上次所在的页、上次用的版本、日历订阅（地址、刷新间隔）与取回的日程。
- 只在内存里、不写笔记的：会面准备（任务页“见面之前”生成的那张单子）、指引当前选中的附带笔记、各页的展开 / 筛选 / 滚动位置。
- 0.3 的手绘动态（风景外层的 `data-ambient` 包裹）、滚动提示三角、今日页空态插图都只在画面里，不写笔记。经 ACP 接入时，对话内容由各家代理按它自己的方式保存会话记录（插件只在本机存对话列表）。
- 风景节点、过场时钟与路径取样、今日页的画面数据、思索天空和灯塔遮罩都是进程内的状态或渲染缓存。它们不写进笔记、插件设置或本机存储。1000 / 5000 篇性能测试用的是沙盒生成的虚构笔记。
